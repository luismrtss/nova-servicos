# NOVA — versão final organizada

Projeto React + Vite + Firebase para conectar solicitantes e prestadores de serviços.

## Funcionalidades
- Cadastro e login com Firebase Authentication
- Perfis de solicitante e prestador
- Solicitação de serviços por categoria
- Categorias da Home pública levando diretamente ao formulário
- Propostas de prestadores
- Aceitar/recusar propostas
- Acompanhamento de serviços
- Início e conclusão de serviços pelo prestador
- Avaliações dos dois lados
- Reputação do prestador
- Perfil com foto via Firebase Storage
- Dashboards separados por tipo de usuário
- Layout responsivo

## Observação
O arquivo `src/firebase/config.js` permanece com a configuração Firebase do projeto fornecido.

Para instalar dependências novamente:

```bash
npm install
npm run dev
```

Para produção:

```bash
npm run build
```
